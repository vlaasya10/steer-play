# Steer Play project guidance

This file records requirements from the Phase 1 brief; no earlier project guidance was present.

- Use React, TypeScript, Vite, Tailwind CSS, Motion for React, React Router and Lucide React. No backend, authentication, database or runtime AI.
- Keep game configuration, scientific copy, shared components and game logic separate. Only enable complete games. Preserve the seven planned experiences.
- Use the official cream, rust, maroon, ink, clay, blush and soft-paper palette defined in the theme. Serif headlines, sans-serif body text, mobile-first layouts and lightweight SVG artwork.
- The project name is Steer Play. Do not introduce alternate project names.
- Health content is educational, qualified and pending clinical review until approved. Never imply diagnosis, medication suitability, medical approval or weight-loss outcomes. Cite real sources. Clinical decisions belong to qualified clinicians.
- Every game completion must include an optional working https://steerclub.com link, replay, optional sharing and a return to the hub.
- Mark simulated advertising and targeting clearly. Never imply access to real engagement history.
- Respect reduced motion, keyboard use, visible focus, readable contrast and 44px minimum touch targets.
- Verify routes, correct/incorrect gameplay, accessible reveal, replay, share fallback, external link, disabled games, responsive widths (360/390/430px), TypeScript and production build.
